# Security Policy

## Reporting a Vulnerability

If you wish to report a security vulnerability but not in a public issue -- thank you! -- we ask that you follow the following process.

- Open a GitHub Security Advisory in this repository under `/security/advisories/new` as the issue can be triaged on GitHub.
- Provide as much information and a possible exploit or threat scenario as possible without disclosing any confidential or sensible data.
- We ask that you please keep the report confidential until we have made a public announcement.

After the advisory has been created, you will receive a response within 7 days.

In addition, you may request that the project provide you a patched release in advance of the release announcement, however, we can not guarantee that such information will be provided to you in advance of the public release and announcement. Once a patch has been created, you will be contacted at the same time the public announcement is made.
