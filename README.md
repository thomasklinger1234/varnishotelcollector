# Varnish OpenTelemetry Collector

---

The Varnish OpenTelemetry Collector is a custom [OpenTelemetry Collector Distribution](https://opentelemetry.io/docs/collector/distributions/) for
[Varnish Cache](https://varnish.org) for collecting metrics, traces and logs from Varnish Cache instances.

Objectives:

- Unified: Single binary to collect traces, metrics and logs from Varnish instances. 
- Embeddable: Add telemetry for Varnish without switching ecosystems or deploy additional software. 
- Performant: Highly stable and performant under varying loads and configurations.
