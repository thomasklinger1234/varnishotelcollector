# Collector RFCs

*This document has been adapted from [opentelemetry/opentelemetry-collector](https://github.com/open-telemetry/opentelemetry-collector/blob/main/docs/release.md).*

This folder contains accepted design documents for the Varnish OpenTelemetry Collector. Proposals here imply changes only
on the Varnish OpenTelemetry Collector and not on other parts of OpenTelemetry; if you have a cross-cutting
proposal, file an [OTEP][1] with the upstream project instead.

## Contents

There is no formal requirement for structure or format. The [OTEP template][2] can be a good starting point for 
proposing new changes and describing your idea.
